# RevitVolumeCalc — объём выделенных элементов (Revit 2024)

Плагин добавляет на ленту Revit вкладку **«Объёмы»** с кнопкой **«Посчитать объём»**. Кнопка открывает немодальное окно. В нём общий объём выделенного и список категорий с объёмом и числом элементов. Щелчок по строке выделяет её элементы в модели.

## Требования

- Autodesk Revit 2024;
- Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений .NET».

Developer Pack для .NET Framework 4.8 не обязателен: нужные сборки подтянутся из NuGet при сборке.

## Сборка

1. Откройте `RevitVolumeCalc.sln` в Visual Studio.
2. Выберите конфигурацию **Release** и выполните **Сборка → Собрать решение**.
3. Результат: `src\RevitVolumeCalc\bin\Release\RevitVolumeCalc.dll`.

Проект ищет `RevitAPI.dll` и `RevitAPIUI.dll` сначала в `C:\Program Files\Autodesk\Revit 2024\`, затем в `D:\Revit 2024\`. Если Revit установлен в третью папку, сборка остановится с ошибкой «Не найдены RevitAPI.dll и RevitAPIUI.dll». Тогда найдите на диске папку, где лежит `RevitAPI.dll`, и впишите её вместо `D:\Revit 2024\` в последнюю из строк `RevitInstallDir` в `RevitVolumeCalc.csproj` (строка без `Exists`). Чтобы открыть файл проекта, щёлкните правой кнопкой по проекту RevitVolumeCalc в «Обозревателе решений» и выберите «Изменить файл проекта».

## Установка

1. Закройте Revit.
2. Откройте папку `%AppData%\Autodesk\Revit\Addins\2024\`.
3. Скопируйте туда файл `src\RevitVolumeCalc\RevitVolumeCalc.addin`.
4. Рядом создайте папку `RevitVolumeCalc` и скопируйте в неё `RevitVolumeCalc.dll`.

Получится так:

```
%AppData%\Autodesk\Revit\Addins\2024\
├── RevitVolumeCalc.addin
└── RevitVolumeCalc\
    └── RevitVolumeCalc.dll
```

5. Запустите Revit. При первом запуске Revit спросит, загружать ли неподписанную надстройку. Выберите «Всегда загружать».

Шаги 3–4 можно не делать вручную. Соберите проект из «Командной строки разработчика» с параметром автоустановки (Revit при этом должен быть закрыт):

```
msbuild RevitVolumeCalc.sln /restore /p:Configuration=Release /p:DeployToRevit=true
```

## Как пользоваться

1. Выделите элементы в модели.
2. Нажмите **Объёмы → Посчитать объём**.
3. Окно не блокирует Revit. Чтобы посчитать новое выделение, нажмите **«Пересчитать»** в окне или снова кнопку на ленте.

## Правила подсчёта

- Берётся только встроенный параметр «Объём» (`HOST_VOLUME_COMPUTED`). Значение переводится в м³ через `UnitUtils`. Объём по геометрии не вычисляется.
- Если у элемента нет параметра или он не заполнен, элемент попадает в строку **«Без объёма»** и в сумму не входит. Нулевой объём считается обычным значением 0.
- Помещения и пространства попадают в «Без объёма»: у них другой параметр объёма.
- Группы, в том числе вложенные, и сборки раскрываются до отдельных элементов. Каждый элемент учитывается один раз.
- Суммы считаются по точным значениям и округляются до 0,01 м³ только при показе. Поэтому сумма округлённых строк может отличаться от общего объёма на несколько сотых.
- Щелчок по строке заменяет текущее выделение в модели. Если после этого нажать «Пересчитать», будет посчитано уже это новое выделение.
